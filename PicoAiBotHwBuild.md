# Pico AI Bot Interposer Build

Rev 0.1 10/14/26

This documentation is provided for remote participants in the DPRG’s “Learn to program an Arduino robot using AI” workshop. It shows how to build the interposer used in the workshop. It should enable remote attendees to build the necessary hardware to participate in the Winky-Blinky Challenge.

You do not need the robot connector shown unless you intend to connect to your own robot. You will be able to participate in the Winky-Blinky challenge using only two LEDs and a Pico.

# Parts Required

* Raspberry Pi Pico with headers  
* Data-capable micro-USB cable  
* Perf board or proto board or solderless breadboard  
* Pin sockets if using proto board \- 5 pins minimum for each side of the Pico  
* 2 Resistors \- any value in the 100 ohm to 680 ohm range  
* 2 LEDs \- any color  
* Wire, solder
