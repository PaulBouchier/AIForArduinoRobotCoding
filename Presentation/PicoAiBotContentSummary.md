## Workflow

- Workflow diagram showing instructions given to AI, AI prints code, user copies code into Arduino IDE, and uses IDE to program Arduino. Arduino gets mounted onto robot and operates it. Use AiArduinoWorkflow.png and following bullets as talking points:  
- **Step 1: Inputting the Instructions**  
  - Explain the robot's intended behavior using simple, natural language.  
  - Feed these functional requirements directly into the AI assistant as a prompt.  
- **Step 2: AI Code Generation**  
  - The AI instantly translates human logic into structured Arduino C/C++ code.  
  - It automatically handles standard structural blocks like setup() and loop().  
- **Step 3: Moving to the Arduino IDE**  
  - Copy the raw code block generated by the AI with a single click.  
  - Paste the script directly into a fresh workspace inside the Arduino IDE software.  
- **Step 4: Flashing the Hardware**  
  - Tether the physical Arduino microcontroller to the computer using a USB cable.  
  - Compile the script and hit the upload button inside the IDE to flash the board's memory.  
- **Step 5: Physical Integration & Operation**  
  - Securely mount the newly programmed Arduino board onto the robot chassis.  
  - Connect a portable power source so the board can read sensors and drive physical motors autonomously.

# Hands-on

## Laptop pre-checks

- Make sure everyone can connect to guest wifi  
- Check everyone has pre-loaded Arduino IDE and Pico support

## Connect Arduino and test example

- Connect Pico to laptop  
- Launch Arduino IDE and open blink example  
- Set the board type (Pico) and port (e.g. /dev/ttyACM0, COM9)  
- Build and program blink example. Observe flashing LED

## Ask AI to write a sketch

- Open up google in AI mode. Give it the following instruction:

> 

  > I have a differential drive robot with two motors controlled by PWM. The PWM signal is produced by a Raspberry Pi Pico. I am using the Arduino IDE with the earlephilhower arduino-pico core. The left motor is driven by GP1. The right motor is driven by GP0. The GPIO pins drive a PNP transistor that enables the motors. When the output is low (PWM \= 0%) the motors run at full speed. When the output is high (PWM \= 100%) the motors are stopped.

  > 

  > Give me an arduino sketch to control the motors as follows. The motors should be stopped for 5 seconds at startup. Then the left motor should ramp to full speed in 1 second then ramp down to stopped in 1 second. Then the right motor should ramp to full speed in 2 seconds, run at full speed for 1 second, then ramp down to stopped in 1 second. Then the sequence should repeat twice after which the motors should stay stopped. 

> 

- Copy the code it produces into the Arduino IDE. Set the board type to Raspberry Pi Pico, and build and load the sketch into the Raspberry Pi  
    
- Look at the LEDs and check that the light pattern is as specified. If results aren't as expected, ask AI to add debug print statements to the sketch. Load the modified sketch and watch the prints with the Arduino monitor. Look at the code. Ask AI how the code works.  
    
- Put your interposer on a robot. Get the wheels off the ground and check that the wheels move as expected. Put the robot on the table and check it spins one way then the other.

## The Challenges

Make a robot do the best break-dancing moves. Get AI to write code that makes the robot move in fun and interesting ways. Spins and herky-jerky is good. It should begin its moves upon power on, and stop when its finished.

Make a 2-LED interposer board do the most fun blinky-light pattern
