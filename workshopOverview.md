# Learn to program an Arudino robot using AI

# WHAT

The October 24th DPRG monthly meeting will offer a workshop where participants
will receive training and hands-on experience learing how to use an AI to program an
Arduino-based microcontroller in C and make it drive a real robot. There
will be a mystery challenge related to robot motion.

# WHERE, WHEN

The workshop will begin at 10am, Saturday 10/24 in the Dallas Makerspace North Lobby classroom, 1825 Monetary Lane, Carrollton. The presentation part will
be available to remote particants via Google Meet at https://meet.google.com/mwm-imzg-rss. The hands-on part will only be available in-person.

# GENERAL INFO

You will need to bring your own laptop, with Arduino IDE pre-loaded. All other hardware will be provided for shared use. You will need working wifi on your laptop. You will use an online AI via the wifi at the facility. There will be assistance available to help with problems.

This is **NOT** a learn-to-write-software class. It is about how to use AI to write robot software. 

**Knowledge Pre-requisite:** you should have looked at some kind of software before, and be familiar with programming constructs like functions, loops and and if() statements. If you don't meet the pre-requisite this workshop is not for you.

**Laptop Pre-requisite:** Windows 10 or newer, Linux, or macOS Monterey or newer. **Pre-load it with the Arduino IDE** from here: https://www.arduino.cc/en/software/#ide

# WORKSHOP CONTENT

## Theory:

- Workflow: AI -> hardware
- Robot + Arduino overview
- PWM and motor speed control

## Practical:

- Configure your Arduino IDE install to build Pico firmware

- Load and run an example sketch on an Arduino

- Ask AI to write code. Run the code on the Arduino

- Design a solution to The Challenge and ask AI to write code that implements your design

- Test the code on the Arduino. If it works, test it on the robot. If it doesn't, ask AI to help you debug it.
