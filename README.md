# Learn to use AI to program an Arduino Robot

This repo contains assets for the "Learn to use AI to program an Arduino Robot" workshop which Paul Bouchier conducted at the October 2026 DPRG monthly meeting.

There is the hardware and construction design for the Interposer board which carries a Raspberry Pi Pico and connects it to Mark Reynold's robot.

The workshop slides are here, and a script to extract a sketch from a downloaded .eml email file and use the Arduino CLI to burn it into a Pico.

The master copy of slides and markdown docs is in Paul's Google Drive, in the DPRG -> 2026 October AI Arduino folder.
